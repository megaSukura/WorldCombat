# 表现数据与几何契约

表现消费机制已经算出的结果。定义字段以[客户端 SDK](../../sdk/client/index.d.ts)为准，载荷与拥有者入口见[WorldFeedback](../../content/mechanisms/world-feedback.ts)。

## 数值与结构

粒子定义中的数值叶可以绑定 `{ data: "路径", fallback: 数值 }`。路径从本次 `data` 开始，支持嵌套对象和数组下标；生产端完成单位转换、取整与限幅。绑定结果继续接受该字段原有的类型和范围校验。

更新载荷会改变后续发射，已经发出的粒子保留出生参数；同一 moment 中已过去的 burst 保持已执行状态。`intensity` 还会缩放发射量；需要按机制计数时让绑定值直接承担数量，统一计算与该倍率的关系。

需要自定义结构、条件、循环或精确的持续图形数量时，使用 `WorldCombatClient.scene` 的回调消费完整条目并绘图。同一场景 id／版本选择一个注册入口；回调句柄随回调返回结束，缓存按生命周期清理。有限粒子 burst 描述发射量，画面存活数还受粒子寿命、LOD 与预算影响。

## 几何与筛选

世界判定使用[WorldGeometry](../../content/mechanisms/world-geometry.ts)的区域与普通谓词组合。查询得到可用生物后，回调按当前观察、关系、可见性、注册表标签及状态身份筛选；非生物对象使用原生实体查询。观察位置是身体中心，查询采用中心距离；具体范围与有效性要求见[世界 SDK](../../sdk/core/world.d.ts)。

路径表现直接消费有序世界顶点。实体顶点随实体移动，数值顶点保持给定位置；offset 作用于顶点，而 body fit、scale 和 orient 用于各自的局部几何语义。需要判定与表现重合时，由机制提供同一份顶点或尺寸，按所属坐标系转换一次。

简单有序凹／凸多边形均可填充，两种绕向使用相同覆盖范围；退化或无法组成有效面的输入停止填充。服务器多边形是水平区域及高度带，客户端绘制顶点组成的面；使用同一平面与高度约定来表达同一个区域。局部线、柱、锥以 +Y 为轴，圆环位于 X/Z 平面，`orient` 再把轴转向选定方向。

水平扇区使用 `sector` 的半径与整张角，配 `orient: "heading"` 只按方向的水平分量转向；`fit: "world"` 按世界单位使用机制尺寸。已有世界顶点继续使用 `path`。三维锥体以局部 +Y 为轴，`angleDegrees` 表示半角。

## 生命周期

动作表现由动作拥有；效果表现由效果或有界回执拥有。更新使用同一逻辑 key，结束时停止发射并按退出方式清理，已经交给粒子系统的粒子自然到期。持久的范围和数量提示可用场景回调逐帧绘制，使其与拥有者同时消失。
