# 即时战斗的共同语义

依据总计划第 5、6、10、11 节。原生个体、培养和资源继续使用原有数据；技能以名称、介绍、设定和原效果为灵感，按世界中的动作、位置和结果重新设计。本文约束 P4 能力实现，具体参数由脚本配置并随 P5 的正式内容试玩调整。

| 原有概念 | 本项目的对应 |
| --- | --- |
| 命中与回避 | 实际轨迹、遮挡和碰撞决定接触；需要精度差异的技能可在发射前生成可见偏差，具体取值由技能设计声明。技能逐项决定追踪、散布及闪避窗口。 |
| 先手与六维速度 | 改变有上下限的准备时间和响应机会；已经发生的动作按实际时序结算。世界移动使用原生当前移动属性与导航倍率，速度状态再作修正。 |
| 持续与周期效果 | 中毒、灼伤、恢复等分别使用自己的逻辑计时。睡眠／冻结限制动作并有恢复事件；麻痹降低移动与准备效率。 |
| 接触 | 由具体动作声明身体接触；远程命中和区域覆盖分别表达自身语义。反伤、吸取和消耗依据实际结果结算。 |
| 换入与遭遇 | 实体放出、收回、实际参战与切换指挥对象分别记录。战斗入场效果随实际参战触发；切换 HUD 保留伙伴安排。 |
| 行动机会与限制 | 蓄力、引导、维持防护占用动作；打断效果声明适用窗口。锁招、资源与授权在共同执行入口复核。 |
| 特性与携带物 | 根据新玩法确定用途，说明触发、作用对象、消耗及结束条件。原生数据接通与世界效果实现分别记录。 |
| AI | 在有限观察和记忆上选择目标、站位与行动。候选提供用途、成本、风险和预期结果；手动与 AI 使用相同参数和结算。 |

P4 的机制样例验证上述表达和组合；P5 逐项设计正式招式、配招和遭遇。原生特性／道具的覆盖以实际实现为准，共同语义成立后继续补齐范围，进入 P5 前复核已知需求。

时间与精度入口见 [native-semantics.ts](../../content/mechanisms/native-semantics.ts)，具体原生效果见 [native-effects.ts](../../content/mechanisms/native-effects.ts)，AI 策略见 [content/tactics](../../content/tactics)。
