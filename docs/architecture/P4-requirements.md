# P4 需求—机制—验证对应

更新于 2026-09-13。本文保存原生事实、即时设计约定和能力缺口；实现及检查结果见 [P4 进度](../development/P4-checks.md)。本表保留覆盖目标，按 P5/P6 的实际设计补充能力；P4 的交付边界见检查记录。

## 原生范围核对

实际依赖与完整专服注册已对齐：936 个招式、314 个特性。另有 537 项上游战斗道具参考及 749 项原生物品注册，后两者用途不同。逐项线索及来源见[原生清单](move-scope.md)。

物种数据的等级、蛋、TM、导师及特殊学习来源已提取。招式的实际获得路径、历史招式与已实现物种的交集继续核对；随机调用、模仿、梦话、挥指、变身及特殊形态产生的招式保留独立调用路径。`custom-callback-review` 表示需要阅读上游回调取得设计素材的条目，机制线索用于发现创作能力需求。具体技能以名称、介绍、设定和效果为灵感重新设计。

| 特殊系统 | 锁定版本可确认的事实 | 首次纳入相应正式内容前完成 |
| --- | --- | --- |
| Mega | 有形态与道具参考数据，原请求检查 `key_stone` | 核对取得、触发、形态同步与恢复入口 |
| Z 招式 | 注册 35 个 Z 招式，有结晶参考，原请求检查 `z_ring` | 明确授权／消耗、招式替换与一次使用的即时边界 |
| 极巨化／超极巨化 | 注册 52 个 Max 招式，保存极巨等级，形态数据有专属招式与限制字段 | 明确体型／碰撞、生命比例、持续时长及复原 |
| 太晶化 | 个体保存太晶属性，原请求检查 `tera_orb` | 明确属性及伤害规则、资源恢复与离场语义 |

原生完整专服注册中未找到上述启动道具及清单中对应的 Mega／Z 道具名称候选。形态数据中的 `implemented` 仍需结合取得与操作入口解释。源码依据为锁定版 [ShowdownActionRequest](https://gitlab.com/cable-mc/cobblemon/-/blob/b33536e8721c9419d664fee15aa9e35cbf1900a8/common/src/main/kotlin/com/cobblemon/mod/common/battles/ShowdownActionRequest.kt)、[Pokemon](https://gitlab.com/cable-mc/cobblemon/-/blob/b33536e8721c9419d664fee15aa9e35cbf1900a8/common/src/main/kotlin/com/cobblemon/mod/common/pokemon/Pokemon.kt)和 [FormData](https://gitlab.com/cable-mc/cobblemon/-/blob/b33536e8721c9419d664fee15aa9e35cbf1900a8/common/src/main/kotlin/com/cobblemon/mod/common/pokemon/FormData.kt)。

当前版本使用可取得的原生功能。上述特殊系统的入口与依赖，在 P5/P6 首次选用相应玩法时集中审阅并实现；最终全技能要求继续保留。

## 即时语义与能力交付

下表是后续内容实现的约定与验收方向。持续时间、反应先后和遭遇边界由脚本表达；宿主提供时间、原生事实和受控操作。具体数值跟随各机制内容实现与试玩调整。

| 需求 | 新玩法与机制落点 | 验证及当前归属 |
| --- | --- | --- |
| 伤害、会心、治疗、吸取、反伤 | 原生攻防与属性作为事实；脚本组合提出、拦截、修改、结算及事后通知；事后记录引用实际 HP 变化 | P4.2 已验证阶段组合；P4.3 验证完整修正链、唯一写入与成长计数 |
| 原生状态、临时强化、特性／携带物 | 原生持续状态保留一份数据；脚本定义周期、行动限制、叠加、免疫、抑制、消耗、恢复及离场规则 | P4.3：施加→实际效果→恢复／捕捉→保存重入，并交叉验证组合 |
| 自定义效果与操作 | 命名状态、事件、处理器和操作；效果自己的规则决定修改、刷新、解除、复制、传递、反射与链接 | P4.2 已有状态、顺序、修改／解除、迁移与卸载基础；复杂操作随 P4.3／P4.4 接入 |
| 多段、蓄力、引导、行动先后 | 使用动作准备、承诺、命中和结束事实；优先度映射到窗口及响应规则，命中判定区分几何接触与效果命中 | P4.4：延迟、多段、打断及同一动作只结算一次资源 |
| 位移与速度 | 世界移动以原生运动能力和当前行为倍率为基准；六维速度、导航速度和动作时序分别由脚本映射 | P4.4／P4.5：原生移动对照、速度效果、可达性与控制交接 |
| 场地、天气、屏障、陷阱、辅助对象 | 状态附着于区域／对象，按来源与所属管理；玩家后续施工保留 | P4.4：进入／离开、世界权限、生命周期与保存；旧岩障／防护迁入脚本 |
| 感知、记忆、诱导和多伙伴 AI | 宿主提供有限观察与动作执行；脚本组织记忆、选敌、追击、站位、授权与候选行动 | P4.5／P4.7：两只伙伴独立执行、切换指挥、原生自由活动与声音诱导 |
| 换入换出、资源及招式变化 | 调用／复制保留动作来源、资源承担者和原生身份；招式锁定、携带物转移及消耗走唯一原生入口 | P4.3／P4.4：临时配招、观察／随机调用、调用链限制、封招和携带物交换已有实际结果；换入换出与特殊资源组合继续实现 |
| 复杂输入与表现 | 多对象、多步骤、路径和持续输入形成版本化参数；表现消费服务端动作事实 | P4.6：快放／预览／引导、取消、必要状态、低粒子与指挥界面 |

来源可获得性、特殊回调与特殊系统的剩余归类随正式内容选题推进；效果协议已支撑原生效果、区域、脚本 AI、复杂输入与表现；当前可运行范围和剩余项以检查记录为准。P4.8 按已交付能力进入正式内容选题，其他需求带着明确归属进入后续设计。
