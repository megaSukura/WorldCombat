# P5 公共创作基础

2026-09-17，根据讨论修订并落实。给创作者的完整入口见[内容生产上下文](../CONTENT_AUTHORING.md)。

- 公共属性在所有精灵上都有基础值。原生事实使用原生来源；新增数值属性注册到 MC Attribute，完整默认覆盖所有生物实体；精灵收回后的保存由适配层接通。枚举、向量和结构继续通过公开个体数据接口提供。属性页显示名称、数值、来源和实际作用，提供中英文。
- MC MobEffect 是持续状态的主要载体。已有状态直接复用，新的共用状态统一定义，独有机制随内容实现。状态可以改变实际行为。上游 168 项留作调查索引。
- 物种习性、性格、特性、技能、装备及其他规则可独立贡献。AI 共用用途和方法，具体差异由事实、规则和个体贡献表达。
- 独立世界行动通过通用动作运行时执行，可由个体或其他来源授予；原生配招与 PP 继续通过原生适配执行。
- 每项内容保有自己的数值公式、全局默认和个体偏好。执行与详情共用计算来源，偏好表达行为取舍和授权。
- 核心 Mod、Cobblemon 适配、共享脚本、最终内容均可扩展，新增逻辑按实际职责落层。

实现入口：[公共值](../../content/mechanisms/individual-attributes.ts)、[公共定义](../../content/mechanisms/pokemon-attributes.ts)、[独立行动](../../content/mechanisms/world-abilities.ts)、[MC 状态操作](../../content/mechanisms/mob-effects.ts)。技术检查与游戏体验分别记录，正式范本按[验收范围](../authoring/accepted-content.md)选取。
