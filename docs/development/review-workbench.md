# 游戏内验收手册

双击根目录的 [启动验收.cmd](../../启动验收.cmd)。脚本固定使用项目要求的 Java 21（`C:\Program Files\Zulu\zulu-21`）；进入独立验收世界后自动打开手册；从左侧选择任意招式，即可带着真实伙伴开始操作。手册放在快捷栏第 9 格，持有后右键打开；F10 也可打开。

## 自由试用

- **自由试验：我的伙伴**：正常走位、施放、选点、取消和指挥。手册里的「鼠标指挥圆盘」使用正式指挥菜单，点击分支、点击指令；G / H / M 及原有技能绑定继续可用。
- **亲自对战：野生宝可梦**：由选中的宝可梦用当前招式与你交战，玩家正常移动、攻击、格挡，自动备好剑、弓、盾、箭与食物。也可随时切换创造或生存。
- 目标可选 MC 生物、宝可梦、玩家本人，以及静止、主动交战、友方。支持多个目标、继续添靶或移除靶子；对手的物种、等级与配招可改。
- 调整个体、追加配招与玩法后，点「布置并进入」。目录上方可切换为给伙伴或对手挑选追加招式。条件工具提供晴雨昼夜、HP / PP、状态、遮挡墙与水池。
- 「作者原场景」是可选的观察入口。自由试验场由你选择对象和操作方式；作者的断言结果只作为那一段场景的记录。

目录支持中文名 / ID 搜索，按原生属性、原生分类、人工标记及有无反馈筛选。分类是原生目录信息，具体即时行为看招式说明和实际操作。选择、标记和记录均留在你所选的招式；分页只翻目录。

## 可编辑反馈

打开「反馈条目 / 复用」，新增条目后自由填写，支持多行；停笔约一秒或关闭面板时保存。每条可以继续改写或删除。右侧历史条目可以搜索、点击复制，再按当前情境修改，其他招式的原条目保持原文。历史是你自己写过的内容。

「标记通过」「记录问题」只记录当前模式与目标范围。「截图并记问题」会先收起面板，截下游戏画面。重新布置、换招、退出重进会保留反馈与已改过的招式偏好。

## 操作预算

一次点击、一次按键或一次连续输入各算一步，实际战斗中的走位、瞄准与多段输入按招式计算。下面从手册已打开算起；从游戏返回手册需要持有工具后右键 **1 步**，切到工具另计 **1 步**。

| 任务 | 准备步骤 |
| --- | --- |
| 首次选择招式并带伙伴试用 | 点击目录中的招式：**1 步** |
| 按名称找一招并试用 | 点搜索框 → 输入 → 点招式：**3 步** |
| 打开完整指挥菜单 | 点「鼠标指挥圆盘」：**1 步**，指令与选目标另计 |
| 追加 MC / 宝可梦靶子、恢复 HP / PP | 点顶部对应按钮：**1 步** |
| 切为人与宝可梦对战 | 打开玩法下拉 → 选亲自对战 → 布置并进入：**3 步** |
| 标记当前招式、重置当前场地 | 点对应按钮：**1 步** |
| 第一次写反馈 | 反馈页 → 新条目 → 点文本框 → 输入：**4 步**，自动保存 |
| 复用已有反馈 | 反馈页 → 点历史条目：**2 步**；需要改写时再点文本并输入 |

## 保存位置

实例为 `runs/review-client`，日常 play 实例与个人存档独立保留。记录在 `config/worldcombat/review.json`，操作与场景轨迹在同目录 `review-events.jsonl`，截图在实例的 `screenshots/`。后续反馈可直接指出招式或让我读取这些记录。

实现入口：[服务端协调](../../mods/cobblemon-world-combat/src/main/kotlin/dev/worldcombat/cobblemon/review/ReviewTool.kt)、[手册界面](../../mods/cobblemon-world-combat/src/main/java/dev/worldcombat/cobblemon/client/ReviewScreen.java)、[场地工具](../../content/smoke/runtime.ts)。集成者装配 Mod 与内容后运行 `python tools/review-client.py prepare` 更新启动包。
