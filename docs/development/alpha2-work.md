# Alpha 2：复杂招式、指挥与机器协作

本轮由三个 Codex 原生子代理与协调者分工，按创意、区分度、表现可读性、玩家体验四方面检查高代码量招式，针对可确定的缺陷修改；同时改善共享指挥、UI 和具体 Mod 联动。招式结论见[抽查记录](../reviews/alpha2-moves.md)。

## 交付范围

- 16 招：真实接触与位移、释放/解除状态、多来源效果、原生攻击减伤、AI 时机以及玩家说明。另完善充电和辅助齿轮的世界用途。
- G 支持短按后点击、子菜单及按需技能项；多点/持续技复用统一输入，临时选项失效取消选点；HUD、H、原生详情与精确预览统一样式和实际改键提示。
- 手动待令等待真实冷却/承诺动作，超距走近，可取消；共享任务退出保留新手动导航，站位目标缓存到到达或目标移动。
- 充电按实际接收把有限余额送入 NeoForge FE，余量与电招加成共用账本。辅助齿轮驱动 Create 原生手摇曲柄，提供正反转、按 PP 支付的有限工作和停止。
- 作业遇敌暂停，改令取消，同目标同模式重复点击保留已付款的进度。共享库负责作业生命周期，独立招式负责成本、公式和规则。
- 可选 JEI 的物品说明由脚本声明，使用原生信息页；可随脚本/语言资源重载更新。未安装 JEI/Create 时，相应入口按实际可用内容提供。

通用接口位于 [world.d.ts](../../sdk/core/world.d.ts) 和客户端 SDK；机器工作的共享执行见 [machine-work.ts](../../content/library/skills/machine-work.ts)，两招保有独立的 machine.ts。新增实现不作为已经过用户认可的创作范本。

## 验证与体验边界

18 招的单元检查及后台场景通过；两招联动的场景含真实 Create 安装，但场景断言覆盖的是保留的战斗功能。共享 AI/任务、UI 状态与真实 Rhino 控件检查已通过。

真实原生机器检查通过：外部侧面 FE capability、模拟与实际接收、容量/速率限制、保护事件、提供方移除、不加载远处区块；原版拉杆默认交互，以及 Create 6.0.10 曲柄的 +32/-32 原生转动。修复了 Create 在事件中完成交互后 cancel+SUCCESS 应视为成功的通用返回语义。

手动导航原生检查已通过：走入真实射程才提交/付 PP，旧任务退出保留新路径，180 刻冷却中同一指令超过 5 秒仍保留并自动施放，取消等待和行走后不补放。完整内容与测试 profile 已装配；统一 Gradle check、原生 Rhino/UI/字体检查与发行构建通过。独立 NeoForge 安装版已加载发行包中的两个 jar 和完整 play 内容：ready=true，正常退出，无脚本错误。新的界面观感、连续指挥手感、JEI 页面与主人指挥机器的完整操作链仍待实际游玩；技术检查仅覆盖明确断言。

升级与使用见 [INSTALL](../../release/INSTALL.md)；完整变更见 [CHANGELOG](../../release/CHANGELOG.md)。保持既有公开仓库的清洁历史，发行包包含两个新版 jar、正式脚本和对应源码。
