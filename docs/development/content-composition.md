# 内容组合与扩展

当前创作入口见[内容生产上下文](../CONTENT_AUTHORING.md)。实现以[单元加载器](../../tools/content-manifest.mjs)、[行为组合](../../content/behavior/composition.ts)和[个体贡献](../../content/behavior/individuals.ts)为准。

一个内容单元拥有独立 ID、源文件和资源，声明实际依赖。目录按具体设计组织。共享库、原生适配、伙伴运行与最终内容分别装配；选集决定要安装的内容。多个单元可以贡献同一个个体、用途或规则，并保留各自身份。

公共属性始终有定义的基础值，默认读取不向所有存档重复写入。新增数值属性使用 MC Attribute 与原生修饰器，永久值随 Cobblemon 个体保存；属性页与执行读取同一数据，值的贡献进入同源说明。独立行动与原生槽位行动共用动作宿主，AI 以能力用途和实时条件选择。

2026-09-17 原有 26 招已[归档](../../archive/skills-2026-09-17/README.md)，原有储光机制及其 UI／AI 贡献随之退出默认内容。保留共享服务、原生规则和基础交互。

工程检查覆盖依赖、资源、协议和运行合同；内容范本的有效范围见[用户验收表](../authoring/accepted-content.md)。
