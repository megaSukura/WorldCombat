# P2 试玩

P2 已完成，头顶文字修复经用户复验通过。实际结果与后续事项见[检查记录](P2-checks.md)。下列清单保留为完整遭遇的操作参考，后续复验按改动选取项目。

P2 冻结试玩版本使用开发指挥面板，所有伙伴共用投射、防护、岩障和冲刺四个开发动作，选招采用简化示例战术。当前开发版本已接入原生配招，操作清单见 [P3 试玩](P3-use.md)。面板操作和战术决策继续依据反馈完善。

## 进入场景

1. 已有场景时进入原存档；本轮存档名称为“新的世界”。首次准备时，创建**创造模式、允许命令、超平坦**的新世界，命名为“P2 遭遇试玩”。
2. 首次准备执行 `/worldcombat demo encounter`。入口准备通道、掩体、高台、两名演练敌人和一只捕捉练习对象，发放工具与精灵球，并切换到生存模式。继续原存档时直接使用已有场景。
3. 选中队伍第一个伙伴，准星朝近处空地按 **R** 放出，等动画结束。先在入口这一侧检查指挥与技能。

## 第一组：移动、防护和施工

1. 准星指向近处地面，按 **G → 守位**。伙伴应走到指定位置；你走开后，它继续守在那里。改为 **G → 跟随**，观察伙伴恢复跟随及头顶的意图／状态文字。
2. 准星朝无人的方向，选择 **G → 保护**，将自己设为保护对象。按 **X**，伙伴接近后提供短时防护；维持期间技能栏显示相应状态。准星直接指向伙伴再按 X，可给伙伴自身防护。
3. 按住**反引号键**，按 **C**，指向附近完整地面；滚轮转向，松开反引号生成岩障。用镐拆掉一格，再放上圆石；约八秒后其余岩障回收，你放的圆石应保留。
4. 按 **V** 让伙伴向准星方向冲刺。再用反引号＋V 预览朝石墙的冲刺，确认终点受碰撞限制。技能结束后伙伴继续执行原有意图。

**观察点：** 守位与跟随是否明确，防护是否能看懂，岩障预览是否贴合实物，挖建和冲刺是否顺手。

## 第二组：捕捉、协同和自主交战

1. 找到近侧的“捕捉练习对象”。指向它，按 **G → 准备捕捉准星目标**；手持原生精灵球，右键投向它，挣脱后可以再投。成功后应只加入一个队伍成员。
2. 按 R 收回当前伙伴，切换选中新捕捉的伙伴，再按 R 放出。按 **M** 查看当前经验，随后用它参与遭遇。
3. 从中间通道接近敌人。先用默认保守防护，自己持工具挖开石墙、增设掩体，按 **Z** 指挥投射，配合 **X** 防护和 **C** 封路。观察敌人的寻路、攻击及实际遮挡。
4. 切换 **G → 自主交战**，把技能 1 切为“手动保留”，观察伙伴停止自动投射而手动 Z 仍可用；重新授权后，观察自动投射恢复。可在同一面板调整追击范围，指向敌人选择“关注”。
5. 让新伙伴完成一次击败，按 M 查看经验增加。测试时伙伴倒下可执行 `/pokeheal`，恢复后继续。

需要补充一个成长练习目标时，可在近侧执行 `/pokespawnat 4232 100 4109 rattata level=1`，再由新伙伴完成击败。

## 保存并反馈

记下当前伙伴的战术、逐槽授权和追击范围；收回伙伴，保存并退回标题画面，再进入同一世界。检查伙伴与经验仍在，重新放出后 G 面板保留设置，现场意图回到跟随。最后保存并退出游戏。

反馈每组是否正常；如有问题，说明做了什么、实际发生了什么即可。低粒子、取消和改键已有第一批实际结果，可按体验需要补试。

可见启动按 [AGENTS.md](../../AGENTS.md) 第 4 节逐批确认。构建、安装依赖见[构建说明](getting-started.md)；准备场景需要命令权限，日常技能与指挥使用普通玩家入口。
