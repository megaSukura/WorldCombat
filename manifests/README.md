# 基线配置

[dependencies.toml](dependencies.toml) 是构建直接读取的 Gradle 版本目录；[third-party.md](third-party.md) 记录来源与复用方式。

[move-ids.txt](move-ids.txt) 是轻量招式标识快照，范围解释见[招式说明](../docs/architecture/move-scope.md)。[prototype-defaults.toml](prototype-defaults.toml) 保存后续适配玩法的参考参数。

构建和实际启动结果统一记录在 [P0 检查记录](../docs/development/P0-checks.md)。
