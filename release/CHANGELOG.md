# 0.1.0-alpha.3

从抽查追查共享缺陷，并修正机器工作的归属。

- FE 供能、Create 曲柄操作拆成独立功能。电属性伙伴可供能；受控伙伴可操作曲柄。不占原生招式位、不消耗 PP，空配招也能工作。原充电/辅助齿轮恢复各自战斗用途。
- 新增显式原生状态租约与共享多来源贡献，修复关系失效残留、重叠来源误清除及原生解除竞态；保留独立持续效果的设计自由。
- 修复四处受击关系判断、两招反击来源，以及五招误算剩余时长。
- 清除十招纯装饰地面替换及相应无用参数/配置，保留其战斗/治疗/物品用途与表现。

更新时替换两个 jar 和本项目脚本。检查及当前边界见 `docs/development/alpha3-work.md`；新的操作体验仍需实际游玩反馈。

# 0.1.0-alpha.2

复杂招式抽查、指挥交互与机器协作更新。升级时一起替换两个 Mod jar 和本项目脚本。

- 抽查并修正 16 个复杂招式：自由落体、捕兽夹、封印、迷人、特性互换、急速折返、力量平分、力量戏法、下压踢、飞膝踢、掷锚、逆鳞、大愤慨、花瓣舞、防御指令、极光幕。涉及实际接触后命中、分段折返、状态解除、多个来源的效果清理、真实减伤及说明与效果一致性。
- G 短按打开后可直接点击指挥，长按松开仍可快选；支持子分类、按需招式指挥和精确选块。G 内施放复用多点与持续输入；失效的临时选项会撤销待选目标。H、原生详情和 HUD 统一样式、留白与改键提示；精确预览使用连续线条。
- 手动施放超距会走近，冷却或当前动作尚未结束时保留待令；可取消或改令。修正旧 AI 任务退出打断新手动导航，以及相对站位不断移动导致迟迟不施放。
- （Alpha 2 历史实现，已由 Alpha 3 替换）充电曾把当次蓄能交给 FE；辅助齿轮曾把曲柄作业绑定到招式 PP。当前版本改为独立工作能力，见上方 Alpha 3 条目。
- 可选 JEI 显示相关物品的技能用途说明。Java 提供原生 FE/方块交互与说明注册接口，具体用途、成本和公式由独立脚本定义。

本轮技术记录见源码中的 `docs/development/alpha2-work.md`。新的 UI 观感和机器协作操作仍待实际游玩反馈；后台检查只证明对应技术事实。756 招的数量不代表逐招人工验收，Alpha 1 的其余已知范围继续适用。

# 0.1.0-alpha.1

首个公开 Alpha：[下载与源码](https://github.com/megaSukura/WorldCombat/releases/tag/v0.1.0-alpha.1)。

- 两个 Mod：通用世界战斗核心与 Cobblemon 适配；脚本提供共享机制和独立内容。
- 正式 play 内容含 756 个招式实现、24 个特性单元；保留培养、配招、PP、捕捉等原生系统接入。
- 伙伴指挥、招式偏好、公式说明与世界战斗表现；MC/Cobblemon 粒子资源由客户端表现层使用。
- 自然生成沿原生配置；整合包可配置速度映射、PP 容量与脱战时间。
- 修复界面更新被异常停止、部分表现参数解析与绑定、临时地形被破坏后无法恢复等问题。

## 当前范围

这是内容覆盖较广、仍在打磨体验的 Alpha。实现数量不代表每招都已人工验收。部分招式的地形替换仍重复，野生行为主要使用通用策略，部分玩法仍偏重宝可梦专有机制；这些将按具体内容继续改进。

当前技术检查包括编译与内容装配、相关 UI/表现检查、原生 PP 与配置集成、地形生命周期回归。多客户端的完整首版联机体验与不同整合包组合仍需要实际反馈；后台检查不替代动态视觉验收。

脚本可以独立于 jar 更新。服务端热重载后的已有野生 AI 恢复尚不完整，复杂 AI 改动通过重新进入单人世界或重启服务器应用；新增 startup 注册也需要重启。客户端脚本与资源需在各客户端更新，当前没有自动代码分发或游戏内 AI 审批执行流程。

地形修复保留仍存在的原方块记录；旧逻辑已经删除记录的坑洞无法凭现存数据自动还原。此版本继续使用现有世界/个体数据格式，尚不承诺跨后续 Alpha 版本直接降级兼容。
